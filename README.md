# Sognalo

Landing page React di Sognalo con hero cinematografica animata tramite GSAP e ScrollTrigger.

## Avvio locale

```bash
npm install
npm run dev
```

## Verifiche

```bash
npm run lint
npm run build
```

## Stack

- React 18 e TypeScript
- Vite
- Tailwind CSS
- GSAP / ScrollTrigger
- struttura componenti shadcn/ui
